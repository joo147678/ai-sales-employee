## A. The opener that gets replies (structure)

1. **Greeting + name** (السلام عليكم يا استاذ X / ازيك يا X).
2. **One specific, verified proof from their own profile, with numbers** ("حققت 835 Purchase بقيمة 1,061,327 جنيه بـ2147x ROAS").
3. **"وده عجبني جدًا"**: this praise is tied to a specific number, so it reads as real. Generic praise doesn't work.
4. **The gap, named precisely** (results shown as Screenshots only / in highlights only / no personal brand behind the results / account has only 9 posts).
5. **What we build, in one sentence** (a content system that turns results and decisions into content that brings qualified leads, "مش مجرد Screenshots").
6. **The free, already-made asset + an easy yes/no** ("عملنا بالفعل Breakdown مخصص لحسابك. تحب نبعتولك الـBreakdown؟ نعم أو لا عادي جدًا").

Why it works: the numbers prove we really looked; the gap is concrete; the ask is tiny and low-risk.
Weak points to fix: ~120–150 words, one block with no line breaks, and the same skeleton in every message (media buyers know each other). **New rule: keep the 6 beats, cut to ~60–80 words, break into 2–3 short lines, vary the wording every time.**

## What killed conversations (never repeat)

| Mistake | Where | Rule now |
|---|---|---|
| Asset sent + "book a Discovery Call" right away, no question | 9 of 9 | Asset = teaser + ONE specific question about it. Ask for a call only after they engage. |
| Price question answered with only a booking link | Ahmed Hussein | Answer the price in one line + offer the 2K session (CONTEXT §4). |
| Long, AI-sounding replies | Mostafa ("ممكن استسمحك توقف نسخ من ال Ai model") | After the first reply: max 3 lines, Mohamed's casual voice (VOICE.md), or a voice note. |
| Pushy / empty follow-ups ("منتظر رد حضرتك", "متنساش تقولنا رأيك", FOMO "براندات ممكن تختار حد تاني") | Islam Khalaf (5 follow-ups), Ahmed Hussein, Seif | Max 2 follow-ups after an asset; each adds something new (an idea, a hook, a question). |
| Middleman confusion (Yassin explaining who Mohamed is) | Seif | Mohamed speaks as himself from the first reply. |
| Broken / wrong links | Islam (404 Loom), Louai (wrong link) | Open every link before sending. Send video as a file on WhatsApp. |
| Same asset sent 3× + broken English ("I wish to be benefited to u") | Ahmed Moetaz | One send. English drafts checked for grammar. |
| Message sent cut off, no question at the end | Megan Johnson | Every message ends with one clear, easy question. |
| Unverified title ("يا دكتور") built into the whole audit | Hamdi | Verify titles; if unsure, use أستاذ and flag it to TL. |
| "الbreakdown مجاني بالكامل" sent alone as a separate message | Hassan, Shoukry, Rony, Ascend | Never send a one-line add-on. It reads as spam. |

## Angle variations used (from the CRM "Angle Used" column)
Proof + Opportunity Cost + Completed Breakdown · Results-to-Personal-Brand System · Proof-to-Content System · Proof-to-Case-Study System · Consultative Positioning (+ Founder Authority / Offer Architecture) · Clear Positioning + Service Architecture / Lead Quality · Niche Authority · Distinctive Method + Executive Authority · Capability Building + Differentiation · Ethical Opportunity Cost (+ Workshop Content-to-Lead).

What we learned about angles:
- **Proof-led angles (results → personal brand / case studies) are the ones that got replies.** They fit Segment A (media buyers with 500K+ results).
- "Opportunity cost" works lightly inside the first message; as a follow-up ("every month you wait…") it reads as pressure. Don't use it in follow-ups.
- Positioning/architecture angles for coaches and consultants got no replies in long English form; they're untested in short Arabic.
